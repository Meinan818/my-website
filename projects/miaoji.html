用说话记账：AI 出草稿，你确认了才真的入账。

它能干什么

  • 聊天记账：说一句「午饭 25，咖啡 18」，AI 整理成草稿；能追问补充，金额和日期说错了也能改，整组确认之后才写进账本
  • 手动记账：首页、聊天、明细三个入口，共用同一套校验，不想聊天的时候直接填
  • 明细：单笔编辑、逻辑删除，按日期 / 收支 / 分类 / 关键词筛选，出结果小计，还能导出 CSV
  • 日历与统计：按天按月看账，月度收支和分类占比，当天明细有入口
  • 个人资料：昵称、签名、预置头像或私有照片（照片在本机裁剪，10MB 以内）
  • 账本保险柜：导出 / 导入整本账，导入只新增不覆盖，不会把你现有的账冲掉
  • 技术形态：前端 Vue 3 + Vite，后端 Java 21 + Spring Boot + MySQL，数据按身份在服务端隔离，AI 密钥只放在后端

我写它的时候

一开始想要的就是「聊天就能记账」，但做的时候发现：AI 认错一次，账就错了。所以中间加了一道草稿确认——它出草稿，我点头，才进账本。宁可多按一下，也不想月底对不上。

现在自己和朋友在用。前端 574 项、后端 94 项测试，两种构建都过。欠着的也很清楚：纯 IP 没有 HTTPS，所以「装到手机主屏」和离线用不了；找回密码和注销账号还没做。
